This is EvenUCan as a web page: nothing to install. It runs in Chrome or
Edge on Windows, Mac or Linux.

The drawing, box design, wiring and ESPHome code all work offline. The
wizard's AI helper (turning your idea into a parts list, and writing
Arduino sketches) uses the internet with a free key from Google Gemini
(or NVIDIA in the desktop program), or your own paid Claude key if you
prefer - or you can choose "Carry on without AI": start from an example
project or tick the parts you have, and the Code tab makes a starter
sketch with your pins filled in.

IMPORTANT: A FREE AI KEY IS NEEDED TO START A NEW PROJECT
  "Describe your idea" - the wizard that turns a plain-English
  description into a parts list, a box and code - needs an AI to do
  that one translation: it is the only part of the whole program that
  has to reach the internet (or your own computer, for Ollama).
  Google Gemini, Groq and OpenRouter (all free, no card
  needed), NVIDIA (free, desktop program only), or your own paid
  Anthropic Claude key all work. Your key is kept in this browser
  only, never uploaded anywhere except the AI company you chose.
  For a fully offline option, choose Ollama instead: a small AI
  running on this computer. This page can reach it directly at
  localhost - no key, nothing sent anywhere. It lists the models
  you've already pulled so you can click one; starting Ollama itself
  needs the desktop program, since a web page can't start a program
  on your computer. Once the AI has turned your idea into a parts
  list, the box designer, the wiring diagram and the ESPHome code all
  run entirely
  on your own computer - no AI or internet needed again for that
  project. Don't want to use AI at all? Click "Carry on without AI"
  instead of describing your idea.

HOW TO START
  1. Unzip this folder (right-click > Extract All). Keep the files together.
  2. Double-click EvenUCan.html. It opens in your web browser.

INSTALLING IT AS AN APP (when it is on a website)
  Where EvenUCan is served from a website over https (for example GitHub
  Pages), Chrome and Edge offer "Install EvenUCan" in the address bar (or
  Menu > Apps > Install EvenUCan). It then opens in its own window with its
  own icon, and keeps working with no internet connection: the first visit
  online fills an offline copy, including the parts library.
  Opened straight from a folder (double-click), everything still works, but
  a browser cannot install a page from a folder, so that button only appears
  when the page is on a website.

THE PARTS LIBRARY (over 2,200 ready-made parts)
  The first time you click Parts > "Browse parts...", it asks for a file:
  choose parts-library.json, eagle-parts.json and kicad-parts.json together
  (all three are in this folder; select them all at once in the file
  picker). Your browser keeps them, so it only asks once.

WHAT'S DIFFERENT FROM THE DESKTOP PROGRAM
  Everything for drawing, printing, the Enclosure Wizard, Wiring and the
  ESPHome file works the same. A web page can't reach the rest of your
  computer, so these need the desktop program (the .exe):
    - "Send to ESPHome" and "Check with ESPHome": in the web version use
      "Save .yaml" and add the file in ESPHome Device Builder yourself.
    - Downloading product photos during the AI look-up.
    - NVIDIA (free) as the AI: NVIDIA doesn't accept requests from a web
      page, so in this version pick Google Gemini (free) or Claude.
  Your parts and drawings are kept in this browser only. To move parts to
  another browser or the desktop program, use Parts > Export... / Import....

  The full guide is "EvenUCan User Manual.pdf". "README - EvenUCan.txt"
  covers the desktop program as well.

CHECKING THE FILES ARE GENUINE
  "SHA256 checksums - Web version.txt" lists a code for each file. To check
  one, open PowerShell in this folder and type, for example:
      Get-FileHash EvenUCan.html
  The code must match the list, and the list on the download page:
      https://github.com/bullbrand/EvenUCan/releases
