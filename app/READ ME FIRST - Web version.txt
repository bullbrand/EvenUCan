This is EvenUCan as a web page: nothing to install. It runs in Chrome or
Edge on Windows, Mac or Linux, and works offline.

HOW TO START
  1. Unzip this folder (right-click > Extract All). Keep the files together.
  2. Double-click EvenUCan.html. It opens in your web browser.

THE PARTS LIBRARY (over 2,300 ready-made parts)
  The first time you click Parts > "Browse parts...", it asks for a file:
  choose parts-library.json, eagle-parts.json and kicad-parts.json together
  (all three are in this folder; select them all at once in the file
  picker). Your browser keeps them, so it only asks once.

WHAT'S DIFFERENT FROM THE DESKTOP PROGRAM
  Everything for drawing, printing, the Enclosure Wizard, Wiring and the
  ESPHome file works the same. A web page can't reach the rest of your
  computer, so these need the desktop program (the .exe):
    - "Send to ESPHome" and "Check with ESPHome": in the web version use
      "Save .yaml" and add the file in ESPHome Device Builder yourself.
    - Downloading product photos during the AI look-up.
    - NVIDIA (free) as the AI: it doesn't accept calls from a web page, so
      this version uses Google Gemini or Claude instead.
  Your parts and drawings are kept in this browser only. To move parts to
  another browser or the desktop program, use Parts > Export... / Import....

  The full guide is "EvenUCan User Manual.pdf". "README - EvenUCan.txt"
  covers the desktop program as well.

CHECKING THE FILES ARE GENUINE
  "SHA256 checksums - Web version.txt" lists a code for each file. To check
  one, open PowerShell in this folder and type, for example:
      Get-FileHash EvenUCan.html
  The code must match the list, and the list on the download page:
      https://github.com/bullbrand/EvenUCan/releases
