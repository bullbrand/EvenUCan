HOW TO CHECK YOUR COPY
----------------------
1. Open the folder that holds the files.
2. Click in the address bar at the top of the window, type  powershell
   and press Enter. A blue window opens in that folder.
3. Type this (with the name of the file you have) and press Enter:

     Get-FileHash "EvenUCan.html"

4. Compare the long code it shows with the one above.
   The same = the file is exactly as it was released. Safe to use.
   Different = do NOT use it. Delete it and download a fresh copy.

   (Capitals don't matter. Checking the first 8 and last 8 characters
   is enough to spot a change.)
