# About EvenUCan

EvenUCan is an app for making electronics projects, with an offline AI helper built in.

## The AI helper

- It runs on your own computer, so no internet is needed.
- Its model is called evenucan-expert. It is built on Qwen Coder.
- It answers questions about electronics, wiring, ESPHome YAML and Arduino (.ino) code.
- Questions about pin numbers are answered from the app's pin tables first.

## What the helper should do

- Use the reference files before its own memory.
- Keep answers short and plain, for people who are new to electronics.
- Say which reference file it used, at the end of the answer.
