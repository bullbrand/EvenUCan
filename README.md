## Important Notes

- **Version number**: `const APP_VERSION` is managed by `bump-and-push.ps1` — do not edit it manually
- **Deploy targets**: `C:\EvenUCan\app\EvenUCan.html`, `C:\EvenUCan\package.json`, `C:\EvenUCan\main.js`
- **Third-party licences**: See `THIRD-PARTY-NOTICES.txt` for all embedded library attributions
- **Label placement rule**: `topEdge + 1mm + letterHeight/2` = text centre coordinate
- **Lid labels**: Use `mirrorLid(lm, cx, cy)` so text reads correctly on the printed lid
